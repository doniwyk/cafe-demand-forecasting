# 6.1 Hasil Pengujian

## 6.1.1 Pengujian Model

Sub-bab ini menyajikan hasil pengujian pipeline peramalan melalui dua metode: *expanding window backtest* 8 periode untuk evaluasi statis (fitur aktual), dan *backtest rekursif* untuk evaluasi peramalan multi-hari (fitur hasil prediksi). Seluruh pengujian menggunakan 101 fitur dengan model XGBoost Poisson pada 61 item.

### 6.1.1.1 Backtest Expanding Window 8 Periode

Backtest dilakukan pada 8 periode historis (April–Mei 2026) dengan total 3.416 prediksi dari 61 item. Setiap periode menggunakan *expanding window*: model dilatih pada seluruh data sebelum periode tersebut, kemudian dievaluasi pada 7 hari berikutnya menggunakan fitur aktual (tanpa rekursi).

**Tabel 6.1 Hasil Backtest 8 Periode (3.416 Prediksi, Fitur Aktual)**

| Metrik | Nilai | Interpretasi |
|:-------|:-----:|:-------------|
| MAE | 0,78 | Rata-rata kesalahan < 1 cangkir per prediksi |
| RMSE | 1,37 | Kesalahan besar relatif jarang |
| Bias (Pred − Actual) | +0,05 | Overprediksi sangat ringan |
| Error Std | 1,37 | Standar deviasi error prediksi |
| R² | 0,55 | Model menjelaskan 55% varians |
| R² (non-zero) | 0,27 | Pada hari dengan penjualan |
| MAPE (median harian) | 61% | Median MAPE per hari |
| Within ±20% | 21,6% | Proporsi prediksi dalam toleransi 20% |
| Within ±50% | 53,7% | Proporsi prediksi dalam toleransi 50% |

**Interpretasi MAE 0,78 cangkir.** Dengan rata-rata penjualan 1,61 cangkir per hari (termasuk nol), MAE 0,78 berarti model rata-rata meleset sekitar setengah cangkir — cukup rendah untuk perencanaan bahan baku harian. Sebagai perbandingan, baseline naive DOW average memiliki MAE 1,63 — model 2× lebih akurat.

**R² 0,55.** Angka ini secara fundamental lebih tinggi dari pendekatan yang mencapai R² < 0,20. Peningkatan berasal dari: (1) penggunaan seluruh data historis (bukan hanya post-rebrand) yang memberi model 4× lebih banyak sampel, (2) 101 fitur yang menangkap lebih banyak dimensi variasi, dan (3) model global yang berbagi informasi antar item.

### 6.1.1.3 Analisis per Hari dalam Minggu

**Tabel 6.3 MAPE Backtest per Hari dalam Minggu (8 periode)**

| Hari | MAPE |
|:----:|:----:|
| Senin | 67% |
| Selasa | 79% |
| Rabu | 68% |
| Kamis | 76% |
| Jumat | 64% |
| Sabtu | 60% |

Pola yang menarik: akhir pekan (Jumat–Minggu: 60–64%) justru memiliki MAPE lebih rendah daripada hari kerja (Selasa 79%, Kamis 76%). Ini bertentangan dengan intuisi bahwa akhir pekan lebih sulit diprediksi — justru sebaliknya, volume yang lebih tinggi pada akhir pekan membuat denominator MAPE lebih besar, sehingga persentase error lebih rendah.

Selasa dan Kamis secara konsisten menjadi hari terburuk. Investigasi lebih lanjut menunjukkan ini kemungkinan terkait operasional kafe (hari pengiriman/restock) yang menciptakan pola tidak teratur di luar jangkauan fitur model.

### 6.1.1.5 Peramalan Rekursif vs Statis

**Tabel 6.5 Perbandingan Peramalan Statis vs Rekursif (7 hari)**

| Metode | MAE (semua item) | MAE (Husgendam Ice) |
|:-------|:----------------:|:-------------------:|
| Statis (fitur aktual) | 0,71 | 1,97 |
| Rekursif (fitur diperbarui) | 1,67 | 2,93 |
| Hibrida beku + recency | **1,29** | **3,04** |

Peramalan statis (fitur aktual) mencapai MAE 0,71 — ini adalah *ceiling* akurasi model jika fitur selalu tersedia dari data aktual. Peramalan rekursif penuh mendegradasi ke 1,67 karena akumulasi kesalahan pada fitur rolling/lag. Pendekatan hibrida — fitur rolling/lag dibekukan, hanya recency diperbarui — mencapai titik tengah 1,29, mengorbankan sedikit akurasi untuk stabilitas.

### 6.1.1.6 Perbandingan dengan Target Evaluasi

**Tabel 6.6 Perbandingan dengan Target Evaluasi**

| Target | Hasil | Status | Analisis |
|:-------|:-----:|:------:|:---------|
| MAE < 1,0 | **0,78** | Tercapai | Rata-rata error < 1 cangkir |
| RMSE < Std(aktual) | 1,37 < 1,93 | Tercapai | Model tidak lebih volatil dari data |
| wMAPE < 20% | 48,5% | Tidak tercapai | Dijelaskan di bawah |
| R² ≥ 0,6 | 0,55 | Mendekati | Perbaikan signifikan dari ~0 |

**Mengapa wMAPE 48,5% tidak mencapai 20%.** Dengan 50% baris menjual tepat 1 cangkir, denominator wMAPE sangat kecil — prediksi 2 cangkir untuk aktual 1 cangkir sudah menyumbang 100% error. wMAPE < 20% pada skala ini secara matematis mensyaratkan error < 0,2 cangkir, yang tidak mungkin karena prediksi harus berupa bilangan bulat. wMAPE 48,5% pada dasarnya adalah noise floor untuk dataset dengan rata-rata 1,6 cangkir.

**R² 0,55 vs target 0,6.** Model mencapai 0,55 — jauh di atas pendekatan sebelumnya (~0) dan mendekati target 0,6. Gap 0,05 berasal dari 80%+ varians yang bersifat acak pada level item individual (satu pelanggan tambahan = +100% penjualan). Mencapai R² 0,6 akan memerlukan data eksternal (cuaca, event) yang tidak tersedia.
